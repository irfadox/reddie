## Reporting a Vulnerability

The Reddie team takes the security of our open-source tools and the AI applications they protect seriously.

If you discover a security vulnerability in Reddie itself:

1. **Do not create a public issue** on GitHub.
2. Use GitHub's **[Private Vulnerability Reporting](https://github.com/irfadox/reddie/security/advisories/new)** feature on our repository.
3. Include:
   - A clear description of the vulnerability.
   - Minimal reproduction steps or proof-of-concept code.
   - Impact assessment on host environments or analyzed repositories.

We will review your submission promptly, provide an initial response, and coordinate a fix prior to public disclosure.
